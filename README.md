# 原型评审官网

本仓库负责产品介绍、使用说明和部署说明，是原型评审平台的独立官网工程。

当前已交付 `W-04` 工程骨架、`W-05` 官网首页及 `W-06` 使用与部署说明：固定依赖及锁文件、静态路由、基础组件、图标主题、产品示意与首页内容，以及十章使用说明和七章部署说明。`W-07` 已补齐布局、主题、焦点和阅读语义细节，`W-08` 已完成静态构建发布配置与站点来源准备；部署结果以远程任务为准，官网阶段是否完成仍须用户明确确认。

## 已确认范围

- 使用 `React` 与 `shadcn/ui`，重新设计界面。
- 纯静态前端，不调用业务后端接口，不处理登录或团队业务。
- 支持电脑和手机展示。
- 提供日间、夜间、跟随系统三种图标式主题选择，切换带颜色过渡。

## 运行环境

使用 `Node.js 24.14.0`、`npm 11.9.0`，具体依赖均固定到精确版本，间接依赖由 `package-lock.json` 固定。首次安装或拉取新锁文件后，在本目录执行：

```bash
npm ci
```

## 本地开发

```bash
npm run dev
```

开发地址为 [本地官网入口](http://127.0.0.1:5173/prototype-review-website/)。端口占用时明确报错，不自动切换端口。

## 类型编译与静态构建

按顺序执行，避免框架的类型生成和构建同时修改生成目录：

```bash
npm run typecheck
npm run build
```

框架原始输出为 `build/client/`，其中预渲染页面包含仓库子路径；整理脚本按固定映射生成最终发布目录 `build/pages/`。最终目录包含首页、`guide/index.html`、`deployment/index.html`、`404.html`、编译资源和站点图标。

不把未知地址重写为首页，不部署运行时渲染服务。此工程没有测试框架或测试命令；类型编译和构建不代表浏览器交互、可访问性或性能测试通过。

## 查看构建产物

构建成功后执行：

```bash
npm run preview
```

访问 [本地静态官网](http://127.0.0.1:4173/prototype-review-website/)。这只提供已构建文件，不调用后端；端口固定为 `4173`。未知地址返回独立不存在页面及对应状态，目录地址使用末尾斜线。

## 配置与界面偏好

使用说明与部署说明的静态内容分别位于 `src/content/guide.tsx`、`src/content/deployment.tsx`，目录与正文共用章节标识。电脑端显示章节目录与当前小节，中等宽度隐藏右侧目录，小屏使用展开目录；点击章节采用原生锚点，滚动时更新当前阅读高亮。

部署页仅为当前已实现的官网命令提供复制按钮。剪贴板返回成功后显示“已复制”并播报；接口不可用或拒绝时明确提示手动选择复制。评审业务部分只说明部署准备，没有未交付的启动命令、配置字段或真实连接参数。

首页产品示意使用本地静态内容和页面结构，支持编号聚焦、当前内容与只读历史切换及放大阅读；不创建评审记录，不上传文件或调用业务接口。手机展示电脑界面的局部示意，完整界面可在放大区域内滚动查看。

`site.config.ts` 是唯一公开构建配置：站点来源、仓库子路径、应用建设状态、源码公开状态及未来的实际应用入口。配置不完整或互相矛盾时停止启动或构建，不猜测地址。

当前应用状态为建设中，不生成进入应用链接；官网源码仓库已公开，页尾提供官网源码入口；评审前端与后端继续保持私有。主题偏好仅保存到浏览器键 `prototype-review.website.theme`，不保存账号、项目、原型或批注；首次没有选择时跟随系统。

颜色切换使用 `220ms ease-out`，仅在主题变化期间启用全站颜色过渡；普通按钮和面板交互使用 `160ms ease-out`。首屏初始化不播放过渡，系统要求减少动效时即时切换。控制台跟踪信息统一以 `[原型评审台官网]` 开头。

## 页面与阅读细节

手机导航与电脑导航共用当前页标记，页内跳转在抽屉退出后将焦点交给目标区块；切回电脑布局时关闭手机抽屉。正文跳转入口可接收键盘焦点，按钮、页签和折叠入口统一使用两像素焦点轮廓与两像素间隔。

说明目录在较矮的电脑窗口中随页面滚动，避免新增目录滚动区；放大示意的滚动限制在对话框内，复制按钮各状态保持宽度。产品示意使用页面结构和矢量图标，没有需要加载的远程截图；站点图标声明固有尺寸。

首页、两类说明继续在构建时生成标题、摘要和规范地址，不存在页面保留禁止索引及独立静态产物。这些是源码实现与静态构建结果，不代表已运行浏览器交互、性能或可访问性测试。
